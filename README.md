# AD3 - Programação Web

Este projeto é uma aplicação simples para exibir informações sobre cursos e professores em uma página web.

## O que contém

- Página inicial
- Listagem de cursos
- Listagem de professores
- Arquivos estáticos e dados em JSON

## Como usar

1. Abra o projeto em uma pasta local.
2. Instale as dependências com o comando:
   ```bash
   npm install
   ```
3. Para rodar o backend, rode:
   ```bash
   node --watch ./index.js
   ```
4. Para rodar o frontend abra diretamente o index.html na raiz do projeto

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
